健康科普公益短片：《被猫狗咬伤后，别赌运气》

【类型】健康科普 / 医疗科普公益短片（非叙事、非氛围片，目标是让观众看懂并照做）
【画面风格】干净、专业、温和的 2D 医疗科普动画
【语言环境】中国大陆普通社区
【受众】普通家庭、儿童家长、宠物接触人群、社区居民
【整体时长】约 85 秒左右（软目标；具体收成几段、每段几拍由你按信息密度决定，不要凑时长，也不要硬塞）

【核心科普信息（必须忠实保留，不许增删医学结论、不许改顺序）】
被猫狗咬伤或抓伤后，不要侥幸、不要拖延。正确做法依次是：
1. 立刻用流动清水 + 肥皂水充分冲洗伤口（是“充分清洗”，不是冲一下）；
2. 尽快到正规医疗机构就诊；
3. 由医生评估暴露风险（按咬伤 / 抓伤 / 唾液接触伤口或黏膜等情况判断）；
4. 按医嘱完成狂犬病暴露后预防——包括接种狂犬病疫苗，必要时使用狂犬病免疫球蛋白。

【基调弧】开头略带紧张（提示风险）→ 中段冷静、专业、可信 → 结尾明确、温暖、有行动号召。

【要传达到的内容点（这是“要讲清的东西”，不是固定分镜，请你自行归并、排序、决定哪些合成一段的多个 beat）】
- 开场事件：社区公园里孩子想摸家养狗，被轻微咬伤/抓伤，家长立刻上前查看（轻微紧张，绝不血腥）。
- 抛出关键：被咬后真正危险的不一定是伤口本身，关键是第一时间有没有做对。
- 第一步冲洗：家长带孩子到水池，用流动清水冲，再配合肥皂水充分清洗。
- 为什么冲洗：用符号化动画表达“冲洗能尽快减少伤口中的病毒风险”（不是真实血腥的伤口特写）。
- 第二步就医：家长带孩子去干净、通用的门诊（不是某家具体医院）。
- 医生评估：医生查看伤口，根据咬伤/抓伤/唾液接触等评估暴露风险——强调“别自己判断，让医生评估”。
- 暴露后预防：规范流程——伤口处理 → 接种疫苗 →（必要时）免疫球蛋白；疫苗= 保护身体的盾。
- 破侥幸：伤口小不等于没风险；动物看起来正常也不等于绝对安全；拖几天再说会错过最佳时机。（用符号化方式表达，不要做成大段文字卡片）
- 收尾：孩子和家长安心离开门诊，阳光温暖；落在“狂犬病可防、不可赌，被咬后请立即处理”的行动号召上。
